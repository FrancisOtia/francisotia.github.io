# Abia Polytechnic Interactive Web Map

An interactive GIS web mapping application of Dr. Ogbonnaya Onu Polytechnic, Aba (formerly Abia State Polytechnic), developed using Mapbox GL JS, GeoJSON, HTML, CSS and JavaScript.

This project provides an interactive visualization of the institution's campus, allowing users to explore buildings, sports facilities and the campus perimeter through an intuitive web interface.

---

## Live Demo

Website

https://francisotia.github.io/abia_poly_map/

---

## Features

- Interactive campus web map
- Building visualization by building type
- Sports fields and recreational facilities
- Campus perimeter mapping
- Feature information on hover
- Responsive legend with expand/collapse toggle
- Search functionality using Mapbox Geocoder
- Current location (Geolocation)
- Zoom and Navigation controls
- Mobile-friendly responsive interface

---

## Campus Layers

The application contains the following GIS layers:

- Campus Buildings
- School Field
- Basketball Court
- Volleyball Pitch
- Campus Perimeter
